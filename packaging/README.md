# Packaging

Desktop packaging metadata for GrammarCraft.

| Path | What |
|---|---|
| `linux/ai.storyteller.grammarcraft.desktop` | FreeDesktop desktop entry (`Exec=grammarcraft %f`, `Icon=ai.storyteller.grammarcraft`) |
| `linux/ai.storyteller.grammarcraft.metainfo.xml.in` | AppStream metadata (`@VERSION@`, `@DATE@`) for Linux software centres |

App icons live under `../assets/app-icon/` and every non-code asset is recorded in `../ATTRIBUTION.md`.
