# Clean-room derivation and verification plan

## 1. Allowed sources

All work in `GrammarCraft` draws exclusively from:

1. **ArtCraft normative standards and shared foundations:**
   - `storytold/craft-contrib`: `standards/clean-room.md`, `standards/licences.md`, `standards/naming.md`, `rfcs/0029-other-companies-names.md`, `standards/house-rules-core.md`, `standards/house-rules-rust.md`.
   - `storytold/craft-libs`: `craft-proof`, `craft-text`, `craft-docx`, `craft-atomic`, `craft-ui-*`, `craft-mcp-server`, `craft-automation`, `docs/clean-room.md`.
   - `storytold/craft-i18n`: `language-data/manifest.toml` (`Embeddable` permissive packs only; `Download-only` packs remain external) and `.tsv` localization catalogs.
   - `storytold/craft-ai-integrations`: `craft-ai-core`, `craft-ai-client`, `craft-ai-native`, `craft-ai-openai`, `craft-ai-engine`, `craft-ai-engine-rten`, `craft-ai-egui`.
2. **Open standards & Unicode specifications:**
   - Unicode UAX #9 (Bidirectional Algorithm), UAX #14 (Line Breaking), UAX #29 (Text Segmentation), IETF BCP 47 language tags, SARIF v2.1.0, JSON-RPC 2.0, CSL / BibTeX / RIS specifications, ISO 690 / APA / MLA / Chicago / IEEE citation format specifications.
3. **Open academic literature & permissive corpora:**
   - Peer-reviewed readability formulas (Flesch 1948, Kincaid et al. 1975, Lucisano & Piemontese 1988 Gulpease, Martins et al. 1996 Flesch PT-BR).
   - Permissive GEC/proofing evaluation corpora (`CC0-1.0`, `CC-BY-4.0`, `MIT`, `Apache-2.0`, `BSD-*`) listed via pinned URL, licence, and SHA-256 manifest in `clean-room/` (downloaded outside git checkout; never `NC` or unclear licences).
4. **Behavioural specifications:**
   - Public product documentation and clean-room behavioural specifications recorded without reading proprietary binaries, bundles, extensions, or internal strings.

## 2. Corpus manifest policy

- Public evaluation corpora and word-frequency datasets are never committed verbatim unless explicitly allowed by `standards/licences.md`. Instead, pinned manifests (`URL`, `version`, `SPDX licence`, `SHA-256`) fetch external files into a gitignored cache via stdlib-only `python -I` scripts.
- Synthetic and adversarial test documents are generated by committed deterministic scripts from original project inputs.
- Private contributor-owned files (if ever referenced for bug reproduction) are recorded by filename, byte size, and SHA-256 hash only—never committed.

## 3. Phases and freeze gates

| Phase | Scope | Freeze deliverable | Maintainer decision gate |
| --- | --- | --- | --- |
| **Phase 0 (M0)** | Governance, assumptions, naming audit (`docs/feature-names.md`), `deny.toml` allowlist | Initial `clean-room/` baseline + `docs/feature-names.md` | Confirm naming clearance (`GrammarCraft` + UI labels) and `deny.toml` policy |

| **Phase 2 (M4)** | Multi-signal tone lexicons, optional permissive ONNX model manifests (`SHA-256`, `MIT`/`Apache-2.0`), local N-gram/MinHash similarity benchmarks | Updated `clean-room/derivation/` + `freeze.md` + `verification.md` + `ATTRIBUTION.md` | Approve any third-party open model weights and optional external `SimilarityProvider` consent policy |

## 4. Questions requiring maintainer decision

1. **Q-01 (`docs/feature-names.md`):** Final sign-off on USPTO/EUIPO/TMview/WIPO Rule 4 trademark search results for `GrammarCraft` and all user-facing panel/category/goal labels before the first public release or store listing.
2. **Q-02 (Corpus selection for M2):** Selection of specific `CC-BY-4.0` / `CC0-1.0` / `MIT` GEC benchmark corpora for English, Portuguese, and Spanish accuracy verification.
3. **Q-03 (Post-M5 external surfaces):** Whether any future browser integration warrants an RFC in `storytold/craft-contrib` or remains strictly covered by the pure-Rust OS accessibility overlay.
